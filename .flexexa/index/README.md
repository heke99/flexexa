# Flexexa generated codebase index

This directory is populated by `pnpm index:codebase`.

Generated files describe package dependencies, source imports, SQL objects/references, environment-variable usage, event occurrences, API surfaces, infrastructure resources and tests. JSON output is intentionally gitignored; CI uploads it as an artifact when needed.

Use:
- `pnpm index:codebase`
- `pnpm impact -- --base origin/main`
- `pnpm verify:affected -- --base origin/main`
